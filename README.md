# Odoyá Shores

Crie um SITE COMPLETO, PROFISSIONAL E RESPONSIVO para o restaurante Bistrô Odoyá Maresias.



IMPORTANTE: não quero apenas um protótipo, wireframe ou uma página inicial. Quero o projeto completo, visualmente finalizado e funcional nesta execução.

Bistrô Odoyá Maresias

Restaurante / gastronomia

Localização:

Culinária:

Brasileira, sul-americana e saudável.



O restaurante também possui opções vegetarianas e veganas.



OBJETIVO



Criar uma presença digital elegante para o Bistrô Odoyá, apresentando a experiência do restaurante e facilitando o contato dos clientes pelo WhatsApp e Instagram.



O site deve transmitir:



- gastronomia

- qualidade

- aconchego

- natureza

- experiência

- praia

- comida artesanal

- sofisticação sem exagero



Não quero aparência de template genérico de IA.



ESTILO VISUAL



Crie uma identidade visual inspirada em um bistrô sofisticado e acolhedor próximo à praia.



Use:



- tons naturais

- verde relacionado à natureza

- tons terrosos

- creme/off-white

- preto ou marrom escuro para textos

- detalhes elegantes



Evite cores neon, excesso de gradientes e aparência tecnológica.



O design deve parecer feito por um designer profissional especializado em restaurantes.



Utilize bastante espaço em branco, tipografia elegante, imagens grandes e uma composição sofisticada.



ESTRUTURA COMPLETA



1. HEADER



Criar:



- nome/logo Bistrô Odoyá

- menu

- Nossa História

- Gastronomia

- Galeria

- Localização

- Contato

- botão "Fale Conosco"



No celular, criar menu hamburger totalmente funcional.



O header deve permanecer elegante durante a navegação.



2. HERO



Criar uma primeira seção visualmente impactante.



Usar uma imagem gastronômica ou do ambiente como destaque.



Título:



"Bistrô Odoyá"



Subtítulo:



"Uma experiência gastronômica acolhedora em Maresias."



Criar dois CTAs:



"Conheça nossa gastronomia"



"Fale conosco"



O botão de WhatsApp deve abrir:



https://wa.me/5511988651059



com uma mensagem pré-preenchida semelhante a:



"Olá! Vim pelo site do Bistrô Odoyá e gostaria de saber mais."



3. NOSSA HISTÓRIA



Criar uma seção apresentando o Bistrô Odoyá de maneira acolhedora.



IMPORTANTE:

Não invente uma história específica do restaurante.



Utilize somente informações que possam ser confirmadas.



O texto deve destacar a proposta gastronômica, o ambiente acolhedor e a experiência proporcionada aos visitantes.



4. NOSSA GASTRONOMIA



Criar uma seção elegante explicando a proposta gastronômica.



Destacar:



- culinária brasileira

- inspiração sul-americana

- comida saudável

- opções vegetarianas

- opções veganas

- pratos artesanais



Não inventar ingredientes, pratos ou preços que não tenham sido fornecidos.



5. DESTAQUES DO CARDÁPIO



Criar cards visualmente sofisticados para apresentar pratos.



Como não foi fornecido um cardápio oficial completo, NÃO invente preços.



A estrutura dos cards deve ficar preparada para receber posteriormente:



- fotografia

- nome do prato

- descrição

- preço

- botão "Tenho interesse"



Se forem utilizadas sugestões de pratos encontradas em fontes externas, trate-as apenas como exemplos e não como cardápio oficial.



6. EXPERIÊNCIA



Criar uma seção destacando a experiência do restaurante.



Pode abordar visualmente:



- ambiente acolhedor

- contato com a natureza

- decoração com plantas

- espaço agradável

- experiência gastronômica

- opções para diferentes preferências alimentares



Não fazer afirmações comerciais que não possam ser confirmadas.



7. GALERIA



Criar uma galeria grande e elegante.



Organizar as imagens em um layout premium.



Priorizar:



- pratos

- ambiente

- detalhes da decoração

- área externa

- experiência gastronômica



IMPORTANTE:

Não utilizar imagens aleatórias de outros restaurantes.



Deixar a estrutura preparada para receber as fotos oficiais do Bistrô Odoyá.



8. AVALIAÇÕES



Criar uma seção de avaliações.



Não inventar depoimentos.



Se avaliações reais forem disponibilizadas posteriormente, criar cards com:



- nome

- avaliação

- comentário

- estrelas



Enquanto isso, deixar a seção preparada para receber avaliações reais.

Nenhum texto pode ficar cortado.



Nenhum botão pode ficar difícil de tocar.



O menu mobile precisa funcionar perfeitamente.



PERFORMANCE

- carregamento rápido

- imagens otimizadas

- código organizado

- boa experiência mobile

- animações discretas



Evitar animações exageradas.
